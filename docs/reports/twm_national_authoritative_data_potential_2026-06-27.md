# 全国权威数据条件下 TWM 能力上限判断

日期：2026-06-27
对象：GIS Data Agent / Territory World Model（TWM）
用途：用于说明如果后续自然资源部提供全国级权威数据，TWM 可以发展到什么程度，以及哪些能力仍需要真实验证。

## 核心判断

如果自然资源部后续提供全国级、权威、可持续更新的数据，TWM 的上限可以从“原型演示”提升到“国土空间治理智能决策底座”。

但能做到什么程度，取决于数据不只是静态图层，而是否包含跨期历史、审批流转、政策动作和结果反馈。

## 第一层：全国级审查与证据引擎

这是最现实、也最先能落地的一层。

如果有全国一张图、三调/年度变更、永久基本农田、生态红线、城镇开发边界、规划分区、建设项目范围、审批材料、规则条款等数据，TWM 可以较快做到：

1. 全国任意区域的项目合规预审。
2. 自动识别项目与耕地、永久基本农田、生态红线、规划管控边界的空间冲突。
3. 输出规则命中、证据来源、涉及图斑、涉及条款、风险等级。
4. 给出“能否直接判断、需要补充什么材料、需要人工复核什么问题”。
5. 把每个结论回到地图上解释，而不是只给文字判断。

这一阶段 TWM 的主要价值是把“看图、查规则、找证据、写审查意见”串成一条可审计流程。

## 第二层：全国级动态模拟器

如果数据不只是现状图层，而是包含多年时序数据，例如历年土地利用变化、项目审批过程、补正记录、执法督察、规划调整、政策动作、后续实际变化，TWM 可以进一步发展为动态模拟器：

1. 预测某类项目或政策动作可能带来的耕地变化、空间冲突概率、补正风险和审批阻滞点。
2. 对比“保护、调整、避让、补划、修复”等不同治理动作的风险和收益。
3. 识别某个区域未来几年更容易出现哪些空间治理问题。
4. 按地区、地类、项目类型、政策约束做差异化模拟。
5. 对结果给出不确定性和证据门槛，说明哪些预测可信，哪些只能作为复核提示。

这一阶段才适合严谨讨论“模型泛化性”，因为可以做跨省、跨市、跨年份、跨政策场景的 holdout 验证。

## 第三层：规划器和政策推演

如果进一步拥有高质量的历史决策结果和真实反馈，TWM 可以发展为可解释的规划器：

1. 给出建设项目选址或调整方案的候选集。
2. 在耕地保护、生态保护、建设需求、规划约束之间做多目标权衡。
3. 找出硬约束阻断方案、低风险可行方案、需要人工复核方案。
4. 对不同政策组合做反事实推演：如果执行某类管控策略，未来空间格局和审批风险会如何变化。
5. 支持省、市、县不同尺度的规划辅助决策。

这一层价值最高，但要求也最高。不能只靠“数据量大”，还需要明确的目标函数、法律规则、政策优先级、人工确认机制和可解释审计链。

## 数据类型与能力边界

全国数据“可用”不等于自动可以得出可靠预测。至少应区分以下情况：

| 数据条件 | TWM 可支持能力 | 不能直接承诺 |
|---|---|---|
| 只有静态权威图层 | 强审查、强证据、强可视化 | 真实预测效果 |
| 有跨期变化数据 | 动态模拟、趋势评估 | 政策因果效果 |
| 有政策动作和审批结果标签 | 行动条件预测、模型训练与验证 | 未验证地区/政策泛化 |
| 有真实反馈和人工复核记录 | 评估 TWM 是否优于人工 GIS、规则引擎、传统优化工具 | 自动替代审批 |

## 推荐发展路径

如果自然资源部提供全国权威数据，TWM 建议按以下路径推进：

1. 先做全国级“规则-证据-地图”审查引擎。
2. 再做跨期动态模拟器。
3. 再做带验证集的行动条件预测模型。
4. 最后做可解释、可审计的国土空间规划器。

## 汇报口径

可以这样表述：

> 有全国权威数据后，TWM 可以从“演示型国土空间世界模型”升级为“全国国土空间治理的可审计模拟与规划平台”；但必须用真实跨期数据和基线对比证明预测、泛化和规划增益，不能只靠数据规模宣称智能。

不建议这样表述：

> 只要拿到全国数据，TWM 就能自动形成可靠预测模型。

更严谨的说法是：

> 全国权威数据能显著提高 TWM 的状态覆盖、证据可靠性和动态验证条件；但生产级预测、泛化和规划增益仍必须通过跨期、跨区域、跨政策场景的真实验证来证明。
