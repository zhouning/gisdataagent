可声明 / 不可声明

可声明 UWM online temporal state update 在真实 OpenAQ 时间序列 holdout 上，显著强于传统静态 baseline suite，并通过时间顺序负控。

可声明 在透明 known-effect simulator 和 proxy target panel 中，空间 Graph-MDP 2-step 搜索优于静态单步启发式，且 offline value model 在 replay holdout 上优于 train-mean baseline。

可声明 learned world-model rollout planner 在 learned dynamics imagination 中优于静态单步和一步 learned policy baseline。

不可声明 UWM planner 已在真实政策 outcome 上优于传统方法。

原因：真实政策 intervention outcome、scene-aligned station-calibrated holdout、因果验证仍缺。
