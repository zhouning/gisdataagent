## 1. 这份文档的目的

本文固定记录当前实现边界，区分“已经实际运行并产生结果”和“仅完成接口准备”，避免把接口、合同或测试夹具误认为已经完成了真实的一二维联合运行。

客户已经提供的真实数据优先使用；客户尚未提供的字段，在原型阶段使用可追溯的公开或参数化数据，并在运行回执中标注来源和替换位置。客户数据不进入公开代码仓库。

### 2.3 已实际运行的一维到二维单向耦合

当前真实链路是：

```text
客户 SWMM OUT
  → 读取节点 overflow_or_flooding_m3s
  → 按节点坐标映射到二维网格单元
  → 聚合成二维源项
  → ANUGA 地表演进
  → 输出积水深度、面积、体积和时间轴
```

已加入子汇水区面积解析，并按映射面积减少二维直接降雨，避免 SWMM 产流和二维直接降雨重复计量。

### 2.4 动态 SWMM API 和交换公式已具备

动态适配器已经支持打开、启动、固定时间窗推进、读取节点水深/水头/入流/溢流，以及写入节点外部交换流量。水头差交换内核已经实现受限孔口流公式：

```text
Q = sign(H_swmm - H_surface) · Cd · A · sqrt(2 g |H_swmm - H_surface|)
```

这些接口在本轮已经被统一执行器组合，并完成局部真实试点；全市规模的接口批量化和性能验收仍未完成。

## 3. 当前明确未完成的事项

### P0：全市规模的同步双向耦合执行器验收

局部试点已经完成以下闭环，但全市规模尚未完成验收：

```text
交换时间窗开始
  → SWMM 推进一个窗口
  → 读取节点水头、溢流和存水状态
  → ANUGA 使用本窗口源项推进
  → 读取映射二维单元地表水位
  → 按水头差计算双向交换量
  → 将地表回流写回 SWMM 节点
  → 记录本窗口质量守恒并进入下一窗口
```

统一的 `CoupledRunner` 已实现，当前需要扩展并验收全市规模的时间同步、节点—单元映射、交换限幅、失败恢复、逐窗口质量守恒和运行回执。

### P0：真实交换接口属性不完整

当前主要使用坐标映射。严谨交换还需要逐节点/雨水口提供：

| 字段 | 作用 |
|---|---|
| `SWMM_NODE_ID` | 一维节点标识 |
| `ANUGA_CELL_ID` | 对应二维单元 |
| `inlet_elevation_m` | 井口/路面交换高程 |
| `opening_area_m2` | 开口面积 |
| `discharge_coefficient` | 孔口/堰流系数 |
| `maximum_exchange_rate_m3s` | 交换上限 |
| `exchange_type` | 雨水口、检查井、溢流口等 |
| `provenance` | 数据来源和质量等级 |

客户未提供的字段可以先采用参数化值，但必须写入回执，不能伪装成客户实测属性。

### P0：全市联合质量守恒回执

局部试点已经逐窗口记录：SWMM 节点存水量范围、二维初末存水量、降雨量、外排量、入渗损失、SWMM→ANUGA 交换量、ANUGA→SWMM 交换量、质量守恒残差和质量门。全市运行还需要把完整 SWMM 系统存水量（含管道存水）纳入同一回执，不能只依赖节点存水量。

### P1：统一时间步

当前历史结果使用 SWMM 30 分钟 OUT 和 ANUGA 30 分钟输出，只适合单向结果驱动。双向运行需要以统一交换窗口推进，内部 SWMM 路由步可以更小，但每个交换窗口都必须有明确的状态快照和交换量。

### P1：二维城市微地形与海岸边界

当前仍缺道路路缘、建筑阻水、桥涵/下穿、雨水口局部微地形、空间糙率、空间入渗、权威岸线、海堤、潮位、风暴潮和海水倒灌等数据。原型使用公开陆海掩膜和固定外边界，后续可直接替换为客户数据。

### P1：空间覆盖闭合与节点处理规则

100 m 结果中，约 145,067 个 SWMM 节点映射到二维域，仍有域外节点及水体掩膜内节点。需要明确域外节点、海域节点、岸线节点和最近陆域重映射的审计规则。

### P1：网格敏感性

已有 250 m 和 100 m 结果，但尚未完成 50 m 对比。需要对最大深度、淹没面积、峰值时刻、体积、交换量、质量残差和重点区域逐项比较。

### P1：多场景全流程

尚未用完整一二维流程运行并形成同一套回执的 2、5、10、25、50、100 年一遇和 2024 年历史暴雨场景。现有 100 年、180 分钟结果属于已完成的重点原型场景。

### P2：交叉模型和 GWM 状态接入

LISFLOOD-FP 尚未对当前阿布扎比结果完成交叉复核；GWM 尚未接入二维水深、积水范围、一二维交换量和潮位边界等联合状态。

### P2：页面生产级性能

100 m 结果较大，仍需验收首次加载、11 帧播放、2D/3D、管网叠加、100/250 m 切换和大结果的矢量瓦片/二进制网格优化。

## 5. 完成标准

只有同时满足以下条件，才可称为“一二维严谨全流程完成”：

- 一维和二维在同一交换时间轴上真实推进；
- 双向交换量来自水头差和接口参数，而不是事后拼接；
- 每个窗口有可追溯输入、输出、交换量和质量守恒回执；
- 失败窗口可定位、可恢复，且不会静默生成不完整结果；
- 客户已有真实数据全部使用，暂缺字段明确标注并可替换；
- 页面可展示二维节点/单元结果、动态时间轴、管网状态和运行回执；
- 多暴雨场景和网格敏感性结果使用同一套数据契约输出。
