# GWM Benchmark V2.0定义与RC1状态

日期：2026-07-23
当前状态：`V2.0-rc1 / PASS_LABELS_PENDING`

## 1. 一句话定义

GWM Benchmark V2.0是一场事先封存的未来考试：模型在不知道2026真实答案时提交空间状态预测，
等完整标签出现后，使用事先固定的评分器统一比较TWM、FLUS和内部基线。

V2.0不是“再增加一些地区”或“再优化一次TWM”。它相对V1.0的实质变化只有一个：
**从已知答案的历史回测，升级为不知道答案的前瞻盲测。**

## 2. V1.0与V2.0的边界

| 问题 | V1.0 | V2.0 |
| --- | --- | --- |
| 标签状态 | 历史标签已经存在 | 提交预测时2026完整标签不存在 |
| 主要目的 | 证明数据、算法和比较流程可以运行 | 检验真实的未来泛化能力 |
| TWM参数 | 可在历史开发过程中改进 | RC1封存后禁止修改 |
| FLUS | 历史完整栅格回测 | 同口径2021-2026前瞻递推 |
| 结果解释 | 事后开发证据 | 有限范围内的前瞻证据 |
| 模型输赢是否影响benchmark完成 | 否 | 否 |

一个benchmark的质量取决于数据和考试规则是否可信，不取决于自己的模型必须获胜。
因此，V2.0即使得到“TWM不如FLUS”的结论，仍然可以是一个合格benchmark。

## 3. V2.0三条测试轨道

### 3.1 Runtime-R1

Runtime-R1检查一次世界模型推演是否可复核：

- 输入遵守版本化的状态、行动、上下文和空间图契约；
- 模型、参数、数据和预测均有SHA256；
- 冻结TWM权重可以确定性重建历史预测；
- 模型路由不能读取隐藏标签；
- FLUS每个种子都有运行谱系和成员预测；
- 最终评分器在标签出现前完成封存。

当前状态为 `benchmark_runtime_contract_ready`。这不等于共享的跨TWM/UWM/AWM Runtime Kernel
产品已经完成，只表示本benchmark所需的运行和审计契约已经成立。

### 3.2 Controlled-C1

Controlled-C1继续使用128个具有精确机制真值的受控样本，检查DAM-GK能否恢复：

- 行动门控；
- 有向关系；
- 软拓扑；
- 一至三步传播时滞；
- 节点状态增量；
- 受影响节点。

这条轨道用于验证Geospatial Kernel的机制能力，但不能据此声称真实土地政策具有因果效果。

### 3.3 Observed-O2

Observed-O2是V2.0的前瞻主轨道：

| 项目 | 冻结值 |
| --- | ---: |
| 地区 | 20 |
| 节点 | 1,055 |
| 有向空间边 | 3,338 |
| 原始分辨率 | 100米 |
| 预测起点 | 2020 |
| 递推年份 | 2021-2026 |
| 最终评分年份 | 2026 |

TWM和FLUS使用相同地区、节点、预测年份和最终标签。FLUS先在完整100米有效栅格上完成ANN
适宜性和元胞分配，再回到1,055个固定节点评分，避免用稀疏节点直接运行FLUS造成不公平。

## 5. 最终评分方法

主指标为20个地区2026变化F1的非加权平均。辅助指标包括：

- 整体变化F1；
- 变化后类别Macro-F1；
- 整体类别Macro-F1；
- Brier概率误差；
- 预测变化数与真实变化数之比。

TWM与FLUS还将按地区做20,000次成对bootstrap，固定随机种子为 `20260723`。
报告会给出差值区间和地区胜、平、负数量，但不会把多个指标混成一个总分。

如果2026真实变化总数少于20，或有真实变化的地区少于10个，模型胜负记为证据不足，
但benchmark仍可完成并发布“结果不确定”。

## 7. V2.0 final的唯一剩余流程

完整2026标签最早只能在 `2027-01-01` 后导出。届时执行：

1. 注册20地区2025和2026年度标签及哈希；
2. 验证标签时间、地区和栅格完全符合RC1协议；
3. 不修改TWM、FLUS、阈值和评分器；
4. 运行一次已封存的统一评分器；
5. 发布所有结果，无论TWM获胜、失败还是统计证据不足；
6. 将状态从 `V2.0-rc1` 更新为 `V2.0 final`。

## 8. 不能声称什么

即使V2.0最终完成，也只能支持“20个现有地区上的2026时间泛化”和同口径TWM-FLUS比较。
它不能自动证明新地区泛化、真实政策因果效果、业务级预测能力、跨领域Runtime Kernel产品完成，
也不能证明一般意义上的TWM或GWM已经全面有效。
