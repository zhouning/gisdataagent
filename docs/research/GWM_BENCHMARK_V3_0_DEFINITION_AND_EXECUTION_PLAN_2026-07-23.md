# GWM Benchmark V3.0定义与执行方案

日期：2026-07-23
当前状态：`V3.0-final / V3_ALL_TRACKS_COMPLETED_VERIFIED`

> 注：`suite_protocol.json` 是预测前冻结协议，仍保留当时的 pending 字段，不得事后改写。
> 城市评分封存状态以 `final_results/final_results.json` 为准；V3全轨道机器状态以
> `final_results/v3_completion_manifest.json` 和 `final_results/v3_completion_verification.json` 为准。

## 1. 一句话定义

GWM Benchmark V3.0是一场新地域迁移考试：模型只读取20个新城市截至2022年的输入，
在不读取这些城市2023-2025答案的前提下提交三年预测，再统一比较TWM、FLUS和内部基线。

V3的核心升级不是数据更多，也不是把旧的“TWM V3历史实验”改名。它相对V2只补一个主要证据缺口：
**模型到了没有参与训练、调参和阈值选择的新地区，是否仍然有效。**

## 2. 为什么这样定义

| 选择 | 优点 | 问题 | 结论 |
| --- | --- | --- | --- |
| 继续等待新的未来年份 | 时间盲测最强 | V2已经承担；V3再次等待没有新增地域证据 | 不选 |
| 把水库和真实行动设为核心 | 可研究行动条件动力学 | 数据准入和因果识别成本高，会再次阻塞版本 | 仅作扩展 |
| 一次完成跨TWM/UWM测试 | GWM主张更大 | 当前共享Runtime和双领域数据尚未就绪 | 留给后续版本 |
| 新地区历史锁箱 | 数据公开、现在可完成、直接补地域泛化 | 标签公开存在，盲性弱于未来盲测 | 选为V3核心 |

这是一个明确的架构取舍：用一个能完成、能证伪的地域迁移问题替代无法按期闭环的大而全目标。

## 3. 与V1、V2及“TWM V3”的关系

| 名称 | 回答的问题 | 标签性质 |
| --- | --- | --- |
| GWM Benchmark V1.0 | 数据、算法、基线和评分流程是否跑通 | 已知历史标签 |
| GWM Benchmark V2.0 | 原20地区上的2026未来预测是否有效 | 真正前瞻标签，等待2027年 |
| GWM Benchmark V3.0 | 完全新地区上的三步迁移是否有效 | 历史标签，流程隔离后揭示 |
| TWM V3 historical backtest | 联合校准是否改善历史变化检测 | 已知结果后的开发实验 |

因此“TWM V3”可以作为未来候选模型之一，但它不是V3 benchmark本身，也不能用它已有的历史成绩
替代新地域锁箱结果。

## 4. 数据详细定义

### 4.1 地区

- 开发集沿用原有20地区；
- 锁箱集新增20个城市；
- 新城市分为东北环渤海、华北平原、东部东南、华南西南和西北5层；
- 每层4个城市；
- 每个地区使用固定 `0.16 x 0.16` 度城市中心窗口；
- 新地区互不重叠，并且不与原20个开发地区相交；
- 地区选择只使用城市位置，没有读取2023-2025土地覆盖标签。

锁箱城市为沈阳、大连、长春、哈尔滨、济南、青岛、石家庄、太原、无锡、温州、南昌、泉州、
昆明、贵阳、南宁、海口、乌鲁木齐、兰州、西宁和银川。精确边界由
`benchmarks/gwm_bench_foundation_v3_0_draft/lockbox_regions.json` 固定。

| --- | --- |
| 土地状态来源 | `GOOGLE/DYNAMICWORLD/V1` |
| Earth Engine项目 | `ee-zn19860115` |

## 5. 标签防火墙

V3使用已经存在的历史标签，因此必须靠执行顺序阻断标签泄漏：

1. 固定协议、20个新地区、输入年、节点规则、模型、阈值和评分器；
2. Phase A只获取2017-2022输入；
3. Phase B运行TWM、FLUS和三个基线，封存预测与环境哈希；
4. 完成确定性或种子完整回放；
5. 只有以上步骤全部通过后，Phase C才允许获取2023-2025目标；
6. 注册目标哈希并运行一次冻结评分器；
7. 发布所有结果，无论TWM输赢。

目标目录为：

```text
data/twm_public_landcover/gee_dynamic_world_v3_lockbox_targets_2023_2025
```

如果在预测承诺完成前取得或读取该目录中的目标像素，当前协议立即失效，必须建立新版本，不能把结果
描述为V3.0-draft1锁箱评测。

必须诚实说明：第三方原则上可以从公开源访问这些历史标签，所以V3只声称“流程封存”，不声称
“标签从未被分析者见过”。V2仍然是更强的未来时间盲测。

## 6. 技术架构

```text
公开数据源
  -> Phase A输入清单与哈希
  -> GWM Runtime-R2
       -> TWM / DAM-GK adapter
       -> FLUS full-grid adapter
       -> persistence / history-only / fixed-adjacency adapters
       -> 三步状态写回、随机种子、资源和证据记录
  -> 统一概率预测合同
  -> Phase B预测承诺
  -> Phase C目标注册
  -> 冻结评分器与公开报告
```

### 6.1 GWM Runtime Kernel：Runtime-R2

Runtime-R2管理模型如何可靠运行，不负责替代模型内部空间动力学。V3要求它统一：

- 版本化状态快照和空间图输入；
- `prepare -> predict -> writeback -> audit`生命周期；
- 数据、环境、模型、种子和预测哈希；
- 确定性模型重放以及随机模型完整种子重放；
- 标签路由隔离；
- 不确定性、资源使用、失败状态和证据边界记录。

V3通过Runtime-R2只能说明benchmark运行契约成立，不能声称跨TWM/UWM的共享Runtime产品完成。

### 6.2 Geospatial Kernel：Controlled-C2

Controlled-C2检查DAM-GK能否把机制迁移到训练时没有出现的图结构：

- 至少512个受控样本；
- 10个随机种子，至少8个达到预先固定的稳定门；
- 更大和不规则空间图；
- 未见关系组合；
- 一至五步传播时滞；
- 软拓扑变化和行动分配变化；
- 无行动、固定拓扑、单关系、无时滞、行动打乱、关系打乱和空间重连对照。

该轨道有精确合成机制真值，用于检验算法实现和受控机制迁移，不能证明现实政策具有因果效果。

正式执行使用128个规则 `4 x 4` 拟合图和512个分布外测试图。测试图全部比拟合图大且不规则，
共18,291个节点、137,012条边；每个测试样本同时包含三种关系，而拟合样本每次只包含两种关系，
并完整覆盖1至5步时滞、连续软拓扑概率、单行动源和双行动源。10个冻结训练种子中8个通过稳定门。

| C2指标 | 10种子均值 |
| --- | ---: |
| 受影响节点状态MAE | 0.004540 |
| 行动门MAE | 0.011814 |
| 软拓扑MAE | 0.083318 |
| 时滞分布MAE | 0.083803 |

七类对照均已报告。除单关系消融为8/10按预期退化外，其余六类均为10/10按预期退化。种子47和
211因软拓扑误差超过预先固定的0.12上限而失败；失败结果被保留，没有换种子或修改门槛。

### 6.3 Observed-O3

Observed-O3在20个新城市上运行真实土地状态递推。所有模型提交相同键：

```text
region_id, node_id, target_year, probability_0 ... probability_8
```

参与比较的固定模型组为TWM/DAM-GK候选、FLUS三种子集成、状态不变、非空间历史和固定邻接空间模型。

## 7. 评分规则

主指标为20地区乘3个预测年份的变化F1非加权平均。辅助指标包括：

- 整体变化F1；
- 变化后类别Macro-F1；
- 整体类别Macro-F1；
- 多类别Brier误差；
- 预测变化量与真实变化量之比；
- 分地区、分年份和分地理层成绩。

TWM与FLUS按地区进行20,000次成对bootstrap，固定种子为 `20260723`。不把多个指标压成一个
含义不清的总分。

若真实变化少于20个节点，或发生真实变化的地区少于10个，模型胜负标为证据不足，但benchmark
仍可发布为“完成但模型比较不确定”。

## 10. V3仍然不能证明什么

即使V3 final完成，也只能支持Dynamic World土地状态任务中有限的新地域迁移、三步开环预测、
受控DAM-GK机制迁移和benchmark级Runtime可复核性。它不能证明：

- 真实政策或行动的因果效果；
- 业务级、实时或运营级预测能力；
- TWM到UWM的跨领域迁移；
- 共享GWM Runtime Kernel产品已经完整；
- 一般意义上的TWM、DAM-GK或GWM有效性。

水库、真实干预和跨领域评测可以继续研究，但它们是独立扩展，不再阻塞V3核心数据集完成。

V3已按固定顺序完成：Phase A输入、Runtime与评分器封印、五模型预测、完整重放、预测承诺、
Phase C目标注册和唯一一次正式评分。预测承诺指纹为：


| 模型 | 地区×年份变化F1 | 整体变化F1 | 类别Macro-F1 | Brier（越低越好） | 预测/真实变化比 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 固定邻接空间 | 0.2138 | 0.2218 | 0.4079 | 0.2611 | 1.1082 |
| TWM / DAM-GK | 0.2029 | 0.2262 | 0.5553 | 0.1456 | 0.4545 |

| 状态不变 | 0.0500 | 0.0000 | 0.6346 | 0.1668 | 0.0000 |

TWM减FLUS的地区配对bootstrap差为 `0.0930`，95%区间为 `[0.0208, 0.1645]`，所以在
本次变化识别主指标上TWM明显高于FLUS。另一方面，固定邻接空间的主指标略高于TWM，说明
TWM虽然超过外部FLUS基线，仍未超过最强简单空间基线。TWM的预测/真实变化比只有 `0.4545`，
主要问题是预测变化偏少；固定邻接更接近真实变化量，但其类别Macro-F1和Brier明显更差。

真实逐步变化共231个，20个地区均至少发生一次变化，超过协议要求的20个变化和10个变化地区，
因此本次模型比较有效，不属于“变化不足”的不确定结论。
