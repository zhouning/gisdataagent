# 给自然资源用户看的说明：TWM 和 GeoSOS/FLUS 到底有什么本质区别？

更新日期：2026-06-20

这份文档给自然资源行业的一线用户、业务处室、规划审批人员、项目汇报对象使用。它不讲算法细节，重点回答用户上来最常问的一句话：

> 你们这个 TWM 和以前的 GeoSOS/FLUS 这类土地利用模拟软件，本质区别是什么？

## 1. 一句话回答

如果只记一句话：

> GeoSOS/FLUS 更像“预测土地利用格局怎么变”的模拟工具；TWM 更像“围绕项目、规则、证据和审批监管做推演的智能助手”。

换成自然资源业务语言：

> FLUS 主要看“这片地未来可能变成什么”；TWM 主要看“这个事能不能办、风险在哪里、证据够不够、需要谁复核、方案怎么改”。

## 2. 最通俗的比喻

GeoSOS/FLUS 像一个土地利用变化沙盘。它能根据历史土地利用、交通、人口、自然条件、土地需求等因素，模拟未来哪里可能变成建设用地、哪里可能保持耕地、哪里可能变成林地或生态用地。

TWM 像一个自然资源业务推演和审查助手。它不只是看土地怎么变，还会把项目、规划分区、永久基本农田、生态保护红线、城镇开发边界、审批记录、证据材料和业务规则放在一起，判断一个行动会带来什么影响。

简单说：

- FLUS 更像“看未来地图怎么变”。
- TWM 更像“帮你判断这个项目或方案能不能过、为什么、风险是什么、证据在哪里”。

## 3. 用户最关心的本质区别

| 用户关心的问题 | GeoSOS/FLUS 更擅长 | TWM 更擅长 |
|---|---|---|
| 未来土地利用格局会怎么变？ | 是 | 可以参考，但不是核心 |
| 哪些地方可能扩张为建设用地？ | 是 | 可以作为输入或辅助判断 |
| 一个建设项目是否压占永久基本农田？ | 不是核心 | 是核心 |
| 是否触碰生态保护红线？ | 不是核心 | 是核心 |
| 是否符合城镇开发边界和用途管制规则？ | 不是核心 | 是核心 |
| 这个项目如果调整范围，风险会不会下降？ | 有限 | 是核心 |
| 系统结论有没有证据链？ | 有限 | 是核心 |
| 哪些结论需要人工复核？ | 有限 | 是核心 |
| 能不能生成审查、监管、留痕材料？ | 不是核心 | 是核心 |

## 4. 两者看的对象不一样

GeoSOS/FLUS 主要看的是“土地类型”：

- 耕地
- 林地
- 草地
- 水域
- 建设用地
- 未利用地

它关心的是这些类型在空间上怎么扩张、收缩、转换。

TWM 主要看的是“自然资源业务对象”：

- 一个建设项目
- 一块图斑
- 一个规划分区
- 一条永久基本农田边界
- 一条生态保护红线
- 一条审批记录
- 一条业务规则
- 一份证据材料
- 一个需要复核的任务

所以它关心的不只是地类变化，而是业务动作带来的风险和责任边界。

## 5. 两者回答的问题不一样

GeoSOS/FLUS 常见问题：

- 2035 年建设用地会扩张到哪里？
- 不同发展情景下，耕地会减少多少？
- 城市增长边界应该怎么划？
- 哪些区域未来土地利用变化压力大？

TWM 常见问题：

- 这个项目是否占用永久基本农田？
- 是否涉及生态保护红线？
- 是否和国土空间规划冲突？
- 如果项目边界往东调整 200 米，风险是否下降？
- 哪些规则被触发？
- 哪些证据支撑这个判断？
- 这个结论能不能直接作为审查意见，还是必须人工复核？
- 最终审计材料能否追溯到原始图层、规则和计算过程？

这就是本质区别：FLUS 更偏“趋势模拟”，TWM 更偏“业务决策推演”。

## 6. 两者输出的东西不一样

GeoSOS/FLUS 通常输出：

- 未来土地利用模拟图
- 多情景土地利用格局
- 土地利用变化结果
- 城市扩张或用地分配结果

TWM 输出的是业务人员能继续办事的结果：

- 风险清单
- 命中的规则
- 涉及的项目、图斑和空间范围
- 证据链
- 约束风险
- 方案调整前后对比
- 是否需要人工复核
- 审查或审计材料

换句话说：

> FLUS 输出一张未来可能怎样变化的图；TWM 输出一套能解释、能复核、能留痕的业务判断。

## 7. 一个自然资源业务例子

假设有一个建设项目，用户问：

> 这个项目能不能批？有没有风险？怎么调整更合理？

GeoSOS/FLUS 可以辅助回答：

- 这个区域未来建设用地扩张压力是否较大。
- 周边土地利用变化趋势如何。
- 在某个发展情景下，这里是否可能转为建设用地。

但它通常不会直接回答：

- 是否压占永久基本农田。
- 是否触碰生态保护红线。
- 是否违反用途管制规则。
- 哪条规则被触发。
- 证据来自哪张图层、哪个字段、哪次空间叠加。
- 是否需要人工复核。
- 调整项目边界后风险是否降低。

TWM 就是围绕这些问题设计的。它会把项目范围、底线管控图层、规划分区、审批记录、规则库和证据链放在一起，输出可复核的判断。

## 8. TWM 不是简单“更高级的 FLUS”

对用户不要说：

> TWM 比 FLUS 高级，所以替代 FLUS。

更准确的说法是：

> 两者解决的问题不一样。FLUS 是土地利用变化模拟工具，TWM 是自然资源治理和规划审查的世界模型。TWM 可以吸收 FLUS 这类模拟结果作为参考，但 TWM 还要进一步处理规则、证据、审批、复核和审计。

也就是说，FLUS 可以成为 TWM 的一个输入或对比基线，但 TWM 的业务目标更靠近自然资源日常工作流。

## 9. 面向用户的推荐话术

### 30 秒版本

> GeoSOS/FLUS 主要回答“未来土地利用格局会怎么变”。TWM 主要回答“某个项目或规划行动会带来什么风险、是否符合规则、证据够不够、能不能形成可追溯的审查结论”。所以两者不是简单替代关系，FLUS 更像模拟工具，TWM 更像自然资源业务推演和审查助手。

### 1 分钟版本

> 以前的 FLUS 这类模型主要把土地看成不同类型的空间单元，模拟未来哪里可能变成建设用地、哪里可能保持耕地或生态用地。TWM 看的是自然资源业务全过程：一个项目、一个规划调整或一个审批动作，会不会压占永久基本农田，会不会碰生态红线，会不会违反用途管制规则，证据从哪里来，结论能不能复核，是否需要人工介入。简单说，FLUS 帮我们看土地利用趋势，TWM 帮我们做带证据链的业务判断。

### 汇报版

> TWM 与 GeoSOS/FLUS 的本质区别在于，GeoSOS/FLUS 是面向土地利用格局演化的模拟系统，而 TWM 是面向自然资源治理行动的证据门控世界模型。TWM 不仅推演空间变化，还把项目、规则、底线管控、审批记录、证据链、复核任务和审计输出纳入统一闭环，更适合支撑用途管制、规划审查、项目监管和自然资源一张图智能应用。

## 10. 客户可能追问及回答

### 问：TWM 能不能做土地利用模拟？

可以做相关推演，但这不是它的唯一目标。单纯土地利用格局预测可以参考 FLUS/PLUS/CA-Markov 等传统模型。TWM 更关注把模拟结果和项目审查、规则命中、证据链、风险解释结合起来。

### 问：那 FLUS 的结果还有用吗？

有用。FLUS 的土地利用情景模拟结果可以作为 TWM 的参考输入、对比基线或外部模拟模块。TWM 不是否定 FLUS，而是把它能做的趋势模拟进一步放进自然资源业务闭环里。

### 问：TWM 最适合解决什么问题？

最适合解决自然资源业务中需要“空间叠加 + 规则判断 + 证据留痕 + 方案推演 + 人工复核”的问题，例如：

- 建设项目合规性审查
- 永久基本农田占用风险
- 生态保护红线冲突
- 城镇开发边界一致性
- 用途管制规则核查
- 规划调整影响评估
- 项目方案调整前后对比
- 审计和监管留痕

### 问：TWM 的结果能直接替代人工审批吗？

不能这么说。更准确的说法是：TWM 帮助业务人员更快发现风险、组织证据、生成可复核材料，并标出哪些结论可以自动通过、哪些必须人工复核。它是辅助审查和辅助决策，不是替代法定审批责任。

## 11. 最后给用户记住的三句话

1. FLUS 看土地怎么变，TWM 看业务动作会造成什么影响。
2. FLUS 输出模拟图，TWM 输出规则、风险、证据和复核结论。
3. FLUS 可作为 TWM 的参考输入，TWM 面向的是自然资源治理闭环。
