# FileGDB ZIP 浏览器接入设计与验证

## 1. B/S 边界

远程浏览器不能把 `D:\\data\\DLTB.gdb` 这样的本机路径交给服务器扫描。GIS Data Agent 提供两种不同入口：

- **浏览器上传**：用户选择本机 ZIP/TIFF，文件内容经过 HTTP 分片传到服务器。
- **扫描服务器受控目录**：只扫描部署主机或 Windows 采集器能够访问、且由 `GDA_LOCAL_INGEST_DIRS` 明确授权的路径。

FileGDB 是目录数据集，浏览器上传时必须把整个 `*.gdb` 目录打包为 ZIP，不能逐个选择内部文件。

## 2. 服务端处理链路

```text
浏览器选择 DLTB.gdb.zip
  -> 创建持久化上传 session
  -> 64 MB 分片上传 + 每片 SHA-256
  -> 服务端合并 + 整包 SHA-256
  -> 原始 ZIP 不可变提交到 Raw
  -> ZIP 中央目录安全预检
  -> 逐文件流式解压到临时目录
  -> 原子提交 Raw 展开目录
  -> 自动发现一个或多个 *.gdb
  -> 内置 pyogrio/GDAL OpenFileGDB 读取图层、字段、CRS、范围和要素数
  -> 深度质量检查
  -> 数据模型匹配、标准化、本体引用绑定和语义层
```

上传完成与数据接入是两个可独立重试的操作。原始 ZIP 已成功入湖后，即使解压、适配器或质检失败，也不要求重新上传。

## 3. 资产身份和血缘

系统不把 ZIP、展开目录和逻辑图层混成同一个对象：

| 层级 | 持久化内容 | 身份证据 |
|---|---|---|
| 原始交付件 | 未修改的 ZIP | 文件 SHA-256、大小、上传 session |
| Raw 展开件 | 安全解压后的目录和 `.gdb` | 文件级 manifest、目录树 SHA-256 |
| 可治理资产 | FileGDB 图层画像 | 图层名、字段、类型、CRS、范围、要素数、质量结果 |

血缘关系为 `upload -> raw ZIP -> expanded tree -> discovered/profiled layer -> quality -> standardized output`。本体只引用通过治理门禁的标准化产物，不复制 ZIP 或全部业务记录。

## 4. ZIP 安全与资源门禁

内置实现逐项读取，不使用不受控的 `extractall`。以下情况会在写入展开区前阻断：

- `..` 路径穿越、绝对路径、Windows 盘符路径；
- NTFS ADS、Windows 保留名、尾随点或空格；
- 符号链接、加密条目、大小写路径冲突；
- 损坏 ZIP、无可用条目，或 FileGDB 上传包内没有 `.gdb`；
- 文件/目录条目数、文件数、单文件大小、解压总量、压缩比或磁盘余量超过配置门限。

当前内置解压只接受 ZIP。RAR/7z 不在离线运行时合同中；TIFF 建议直接上传。一个 FileGDB ZIP 可以同时包含多个 `.gdb` 和配套 TIFF，系统会分别发现并登记。

## 5. 断点续传

上传 session、分片回执和校验值都持久化在文件湖。页面用文件元数据加首尾采样 SHA-256 识别可恢复会话。刷新后浏览器不能自动重新取得本机文件权限，用户需重新选择同一文件；系统随后只上传缺失分片。上传完成但解压失败时，再次操作只重试接入阶段。

对数十 GB 以上的常态化批量汇聚，Windows 采集器仍是更合适的入口；浏览器分片上传用于人工交付、跨机器访问和临时批次，两者复用同一 Raw、manifest、质量和血缘合同。

## 6. 重庆真实 FileGDB 验证

2026-08-08 使用本机重庆规划院 `GDB.gdb` 副本打包为 39 MB ZIP，按上传 session 的真实服务链路执行：

- 解压后约 57 MB、50 个 ZIP 条目，发现 `GDB.gdb`；
- 使用内置 `python_gis_runtime`，不依赖 ArcPy/MCP；
- 读取 `DLTB` 图层 1 个、101,657 个要素、11 个属性字段；
- 生成原始 ZIP SHA-256、展开目录树 SHA-256和完整血缘；
- 深度质检实际读取 101,657 个要素后完成，状态为 `review`；
- 图层字段映射为 `manual_review`，原因是重庆样例缺少宁夏 DLTB 基线要求的 `MSSM/QSXZ/SJNF/TBBH/TBDLMJ`；深度质检还发现 180 个无效几何。两者都不是 ZIP、FileGDB 或 GIS 适配器读取失败。

自动化测试同时覆盖合法 ZIP、路径穿越、绝对/盘符路径、符号链接、无 `.gdb`、解压体积门限和重复接入幂等性。
